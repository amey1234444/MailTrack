# Uiverse switch attribution

The switch visual in `components/ui/switch.tsx` and `app/globals.css` is adapted from https://uiverse.io/cssbuttons-io/mean-dolphin-24 by cssbuttons-io (cssbuttons.io). Changes include a sage palette, adjusted sizing, native button keyboard behavior, accessible switch state, pending/disabled handling, focus treatment, and reduced-motion support. Other UI refinements are original project styles.
